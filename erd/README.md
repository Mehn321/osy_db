# Municipal KK Profiling System — ERD Documentation

This folder contains the Entity-Relationship Diagram (ERD) for the **Municipal KK Profiling System** database, normalized from **1NF through 5NF**.

## Files

| File | Description |
|------|-------------|
| `erd_normalized.html` | Interactive visual ERD rendered with Mermaid.js |
| `normalization_notes.md` | Detailed normalization analysis (1NF → 5NF) |
| `database_normalized.sql` | Complete SQL schema for the normalized database |

## Quick Start

Open `erd_normalized.html` in any modern browser to view the interactive ERD diagram.
